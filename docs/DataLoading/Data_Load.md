# Data Load

## Introduction to Data Load

Azure and Google Cloud only: The Actian Data Platform Data Load enables you to load table data from UTF-8 delimited text files from your local machine into a running Actian warehouse. ]

Loading data in this way creates a new configuration that records basic details that can be used over again.
