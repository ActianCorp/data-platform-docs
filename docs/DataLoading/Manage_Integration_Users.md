## Manage Integration Users

You may enable or disable Admin privileges for users or activate or deactivate account users.

To enable or disable Admin privileges for a user

1. On the navigation pane on the left, click User Management.

    The User Management page is displayed, listing all Actian Data Platform account users.

2. Click the Admin toggle to activate or deactivate the user.

To activate or deactivate the user

Click the Active toggle to activate or deactivate the user.

Deactivated users will still be able to log in to the Actian Data Platform and interact with warehouses including using the Query Editor, but the Integrations menu will be disabled.

To search for a user

1. Click the Search icon to open the Search field.
2. Enter your search text, for example, all or part of the username you want to find.

    Matching usernames are displayed.

3. Click the X on the Search field to clear the entry and redisplay all usernames.
