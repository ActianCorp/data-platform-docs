# Managing Integration Users, Groups, and Listeners

If you are enabled as an Actian Data Platform account administrator, you may modify Integration users, groups, and listeners.

Open the Administration interface

In the upper right corner of the Actian Data Platform window, click the user menu and select Administration:

![](images/AdministrationMenuItem.png)

The Administration interface opens in a new browser tab.
