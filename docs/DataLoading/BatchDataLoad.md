# Batch Data Loading

You can load data from a variety of sources into your Actian warehouses by running integrations. You can create, design, and manage your integrations through Integrations on the Actian Data Platform.

You can find information to set up and run your data integrations in [Creating Integrations](../Integrations/Creating_Integrations.md) and [Managing Integrations](../Integrations/Managing_Integrations.md).
