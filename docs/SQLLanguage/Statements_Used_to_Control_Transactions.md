## Statements Used to Control Transactions

The primary statements used to control transactions are:

- COMMIT
- ROLLBACK

In some circumstances, the DBMS terminates a transaction with a rollback. For more information, see [Abort Policy for Transactions and Statements](../SQLLanguage/Abort_Policy_for_Transactions_and_Statements.md).
