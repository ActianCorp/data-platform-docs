## ROLLBACK

[Valid in](../SQLLanguage/Statement_Contexts_(Valid_in).md): SQL, ESQL, DBProc, OpenAPI, ODBC, JDBC, .NET

The ROLLBACK statement rolls back the current transaction.

This statement has the following format:

```
ROLLBACK [WORK];
```
