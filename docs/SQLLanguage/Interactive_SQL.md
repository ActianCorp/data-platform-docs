## Interactive SQL

Interactive SQL statements are entered through the [Actian SQL CLI](../SQLLanguage/Actian_SQL_CLI.md).

## The Actian SQL CLI, a Line-based Terminal Monitor

The Actian SQL CLI is installed with the [Avalanche Client Runtime Package](../User/Access_Warehouse_or_Database_Connection_Informat.md). It accepts SQL statements in a line-oriented style. You invoke the line-basedSQL CLI by typing **sql**at the operating system prompt (for example, the Windows Command Prompt window). For more information, see [Start the SQL CLI](../SQLLanguage/Start_the_SQL_CLI.md).

You can use the statement help sql to display information about SQL statements, tables, views, and other database objects.

For a complete discussion, see [Actian SQL CLI](../SQLLanguage/Actian_SQL_CLI.md).
