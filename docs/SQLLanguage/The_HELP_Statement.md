## The HELP Statement

The HELP statement displays information about a variety of SQL statements and features.

For more information, see [HELP](../SQLLanguage/HELP.md), where all available formats are listed. Also see [HELP Examples](../SQLLanguage/HELP.md).

To see the syntax of the HELP statement in the Actian SQL CLI, type HELP HELP.
