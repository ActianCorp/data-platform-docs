# Keywords

## Reserved Keywords and Identifiers

You should avoid assigning object names that use the keywords listed in this section. In addition to the keywords, all identifiers starting with the letters ii are reserved for system catalogs.

The keywords listed do not necessarily correspond to supported Actian Data Platform features. Some words are reserved for future or internal use, and some words are reserved to provide backward compatibility with older features.
