## Is Within Range

| Rule | IsWithinRange |
| --- | --- |
| Default Rule Name | <fieldname>_IsWithinRange |
| Description | Checks whether a field value is within a specified range. Values within the specified range are written to the Pass Target. Values that are not within the specified range are written to the Fail Target. |
| Rule Parameters | • Lower Bound: The lower range value. Select Inclusive to include the lower bound number in the range.<br>• Upper Bound: The upper range value. Select Inclusive to include the upper bound number in the range. |
| Supported Data Types | Date, Timestamp, Numeric, Double, Float, Long, Integer |
| Remarks | None |
