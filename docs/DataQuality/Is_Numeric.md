## Is Numeric

| Rule | IsNumeric |
| --- | --- |
| Default Rule Name | <fieldname>_IsNumeric |
| Description | Checks whether a string field is numeric. Numeric values are written to the Pass Target. Non-numeric values are written to the Fail Target. |
| Rule Parameters | None |
| Supported Data Types | String |
| Remarks | None |
