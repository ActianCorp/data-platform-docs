## Is Not Null

| Rule | IsNotNull |
| --- | --- |
| Default Rule Name | <fieldname>_IsNotNull |
| Description | Checks whether a field is not null. Values that are not null are written to the Pass Target. Values that are null are written to the Fail Target. |
| Rule Parameters | None |
| Supported Data Types | String, Date, Timestamp, Boolean, Numeric, Double, Float, Long, Integer |
| Remarks | None |
