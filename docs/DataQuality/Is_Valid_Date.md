## Is Valid Date

| Rule | IsValidDate |
| --- | --- |
| Default Rule Name | <fieldname>_IsValidDate |
| Description | Compares the value from the source field with the selected date format. This metric will provide a list of date formats to choose from.Values that match the specified date format are written to the Pass Target. Values that do not match the specified date format are written to the Fail Target. |
| Rule Parameters | **Date Format**: Select from one of the following date formats:•yyyy-M-dd•yyyy-MM-dd•MM/dd/yy•M/dd/yyyy•MM/dd/yyyy•M-dd-yyyy•MM-dd-yyyy•dd-MM-yyyy•MMM dd, yyyy |
| Supported Data Types | String |
| Remarks | None |
