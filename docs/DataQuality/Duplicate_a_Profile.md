## Duplicate a Profile

You can duplicate a Data Profile, edit it, and reuse it.

To duplicate a profile

1. Click the Data Quality link at the top of the page.

    The Data Profiles page (see [Data Profiles Page](../DataQuality/Data_Profiles_Page.md)) displays the available profiles.

2. Select the desired profile by clicking the check box in the tile, then click ![](images/Design_78.png) in the menu that appears.

    A copy of the selected profile is created with “- Copy” appended to the name. It appears on the IData Profiles page.
