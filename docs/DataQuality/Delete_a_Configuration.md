## Delete a Configuration

You can delete a configuration that you have created. Once a configuration has been deleted, it cannot be restored. Deleting a configuration does not delete the profile it’s associated with.

There are two ways you can delete a configuration:

- From the Configurations page. See [To delete a configuration](../DataQuality/Delete_a_Configuration.md), below.
- From the Configuration Details page. See [View Configuration Details](../DataQuality/View_Configuration_Details.md).

To delete a configuration

1. Click Manage, Configurations.

    The Configurations page displays the available configurations.

2. Click ![](images/Manage_29.png) next to the configuration, then select Delete.

    Or, select the configuration by clicking the checkbox next to it, and then clicking ![](images/Manage_30.png) in the menu that appears.

    The Confirm Delete dialog is displayed.

3. Click DELETE.
