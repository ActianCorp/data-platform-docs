## Is Valid Time

| Rule | IsValidTime |
| --- | --- |
| Default Rule Name | <fieldname>_IsValidTime |
| Description | Compares the value from the source field with the selected time format. This metric will provide a list of time formats to choose from.Valid time values are written to the Pass Target. Invalid time values are written to the Fail Target. |
| Rule Parameters | **Time Format**: Select from one of the following time formats:•HH:mm:ss•HH:mm•hh:mm:ss•hh:mm aa•hh:mm:ss a |
| Supported Data Types | String |
| Remarks | None |
