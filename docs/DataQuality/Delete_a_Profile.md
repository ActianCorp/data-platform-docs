## Delete a Profile

You can delete a profile that you have created by following the steps below. Once a profile has been deleted, it cannot be restored.

To delete a profile

1. Click the Data Quality link at the top of the page.

    The Data Profiles page (see [Data Profiles Page](../DataQuality/Data_Profiles_Page.md)) displays the available profiles.

2. Select the desired profile by clicking the check box in the tile, then click ![](images/Design_81.png) in the menu that appears.

    The Confirm Delete dialog is displayed.

3. Type DELETE to confirm (this is case sensitive).
4. Click DELETE.

    The selected profile is deleted and no longer appears on the Data Profiles page. This action is permanent and cannot be reversed.
