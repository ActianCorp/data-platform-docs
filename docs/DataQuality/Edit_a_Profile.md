## Edit a Profile

There are two ways you can edit a profile:

- From the Data Profiles page.
- From the Profile Details page.

To edit a profile

1. Click the Data Quality link at the top of the page.

    The Data Profiles page (see [Data Profiles Page](../DataQuality/Data_Profiles_Page.md)) displays the available profiles.

2. Do one of the following:

    - Select the desired profile by clicking the check box in the tile, then click ![](images/Design_79.png) in the menu that appears.

    - Click the tile of the desired profile. The Profile Details page is displayed. Click the down arrow icon on the Run Data Profile button and select Edit Data Profile.

    The Edit Profile page is displayed. By default the focus is on the Rules page. Navigation between pages is possible by using the Back and Continue buttons at the bottom of the page. When navigation to other pages is not possible, the button will fade in color and will not be active.

3. Navigate to the desired page to view the current profile information and edit it. You can edit the following pages:

    - Description – See [Describe Data Profile](../DataQuality/Describe_Data_Profile.md).

    - Source – See [Define Source](../DataQuality/Define_Source.md).

    - Rules – See [Define Rules and Analyze Results](../DataQuality/Define_Rules_and_Analyze_Results.md).

    - Targets – See [Define Targets](../DataQuality/Define_Targets.md).

    - Results – See [Results](../DataQuality/Results.md).

4. Once editing is complete, navigate back to the Results page and perform one of the following actions:

| Actions | Description |
| --- | --- |
| Save & Schedule | Click this to save the data profile and create a schedule for its execution. |
| Save & Close | Click this to save and close the data profile. Focus is directed back to the Data Profiles page. Use this option if you have incomplete work and want to resume working later. You can search, view, and edit the profile from the Data Profiles page and edit it later. See [Search Data Profiles](../DataQuality/Search_Data_Profiles.md). |

!!! warning "Important"

    **IMPORTANT!**The Cancel Editing the Data Profile dialog appears when attempting to navigate away from the Edit Data Profile page. From this dialog, you have two options: save the changes to the profile and close the editor by clicking Save and Close, or return to the editor by clicking Continue Editing or the “X” button.
