## Search a Rule Set

The Rule Sets page displays all the rule sets and allows you to manage them. The search functionality allows you to search for rule sets by specifying a search text.

To search a rule set

1. Click the Data Quality link at the top of the page and then click Rule Sets.

    The Rule Sets page displays the available rule sets.

2. Enter a rule set name in the Search box and click ![](images/Design_84.png) to search it.

    You can also perform the following actions:

| Options | Description |
| --- | --- |
| ![](images/Design_85.png) | Click this icon to search for specific Rule Sets by their name within the rule set listing. Contents will be filtered based on the search string.Click ![](images/Design_86.png) to clear the search box.**Note:**The search functionality applies to rule set names only, not to the individual rules within the rule sets. |
| ![](images/Design_87.png) | Click this icon and select Name, Date or Created By to sort the list of Rule Sets by one of those fields.Click ![](images/Design_88.png) to clear the filter. |
| ![](images/Design_89.png) | Click this icon to view the Rule Sets in a grid view (the default view). |
| ![](images/Design_90.png) | Click this icon to view the Rule Sets in a list view. |
