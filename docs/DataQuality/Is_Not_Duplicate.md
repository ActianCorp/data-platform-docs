## Is Not Duplicate

| Rule | IsNotDuplicate |
| --- | --- |
| Default Rule Name | <fieldname>_IsNotDuplicate |
| Description | The first instance of a value is written to the Pass Target. If there is a second instance of the value then it is written to the Fail Target. |
| Rule Parameters | None |
| Supported Data Types | String, Date, Timestamp, Boolean, Numeric, Double, Float, Long, Integer |
| Remarks | None |
