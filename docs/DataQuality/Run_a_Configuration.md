## Run a Configuration

This topic describes how to execute a configuration manually. To execute a configuration via schedule, see [Schedule a Configuration](../DataQuality/Schedule_a_Configuration.md).

There are two ways you can run an active configuration manually (without a schedule):

- From the Configurations page. See [To run a configuration from the Configurations page](../DataQuality/Run_a_Configuration.md), below.
- From the Configuration Details page. See [View Configuration Details](../DataQuality/View_Configuration_Details.md).

To run a configuration from the Configurations page

1. Click Manage, Configurations.

    The Configurations page displays the available configurations.

2. Click ![](images/Manage_24.png) next to the configuration, then select Run.

    When the configuration has finished executing, runtime metrics are available for review. See [Run History](../DataQuality/Run_History_2.md).
