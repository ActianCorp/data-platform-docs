## Search Data Profiles

The Data Profiles page displays all the profiles and allows you to manage them.

To search a profile

1. Click the Data Quality link at the top of the page.

    The Data Profiles page (see [Data Profiles Page](../DataQuality/Data_Profiles_Page.md)) displays the available profiles.

2. Enter a profile name in the Search box and click ![](images/Design_62.png) to search it.

    You can also perform the following actions:

| Options | Description |
| --- | --- |
| ![](images/Design_63.png) | Click this icon to search for specific text within the profiles listing. Contents will be filtered based on the search string.Click ![](images/Design_64.png) to clear the search box. |
| ![](images/Design_65.png) | Click this icon and select a connector to filter the list of Data Profiles by connector.Click ![](images/Design_66.png) to clear the filter. |
| ![](images/Design_67.png) | Click this icon and select Name, Date or Created By to sort the list of Data Profiles by one of those fields.Click ![](images/Design_68.png) to clear the filter. |
| ![](images/Design_69.png) | Click this icon to view the Data Profiles in a grid view (the default view). |
| ![](images/Design_70.png) | Click this icon to view the Data Profiles in a list view. |
