## Run a Profile Manually

There are three ways you can run a data profile manually (without a schedule):

- From the profile Editor. See [Creating a Data Profile](../DataQuality/Creating_a_Data_Profile.md).
- From the Data Profiles page. See [Data Profiles Page](../DataQuality/Data_Profiles_Page.md).

- From the Profile Details page. See [View Profile Details](../DataQuality/View_Profile_Details.md).

The runtime metrics are available for review after a profile is run. See [Run History](../DataQuality/Run_History.md).

To run a profile

1. Click the Data Quality link at the top of the page.

    The Data Profiles page displays the available profiles.

2. Do one of the following:

    - Select the desired profile by clicking the check box in the tile, then click ![](images/Design_77.png) in the menu that appears.

    - Click the tile of the desired profile. The Profile Details page will be displayed. Click the Run Data Profile button that can be found in the upper right hand corner of the screen.

    Once execution has been initiated, the Run History screen will appear. From this page you can track the status of your Profile Job (see [Run History](../DataQuality/Run_History.md)).
