## Is Not Blank

| Rule | IsNotBlank |
| --- | --- |
| Default Rule Name | <fieldname>_IsNotBlank |
| Description | Checks whether a field is not blank or empty. Values that are not blank are written to the Pass Target. Values that are blank are written to the Fail Target |
| Rule Parameters | None |
| Supported Data Types | String |
| Remarks | Null, white space, and empty strings are considered as blanks. |
