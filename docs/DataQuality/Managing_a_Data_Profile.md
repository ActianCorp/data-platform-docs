## Managing a Data Profile

!!! note "Note"

    For information on creating a new Data Profile, see [Creating a Data Profile](../DataQuality/Creating_a_Data_Profile.md).

All your Data Profiles are displayed on the Data Profiles page (see [Data Profiles Page](../DataQuality/Data_Profiles_Page.md)). You can open the Data Profiles page by clicking the Data Quality menu option from the home page. The following actions can be performed once an existing Profile has been selected:

- [Search Data Profiles](../DataQuality/Search_Data_Profiles.md)
- [View Profile Details](../DataQuality/View_Profile_Details.md)

- [Edit Profile Schedule](../DataQuality/Edit_Profile_Schedule.md)
- [Run a Profile Manually](../DataQuality/Run_a_Profile_Manually.md)

- [Duplicate a Profile](../DataQuality/Duplicate_a_Profile.md)
- [Edit a Profile](../DataQuality/Edit_a_Profile.md)

- [Save Profile Rules as Rule Set](../DataQuality/Save_Profile_Rules_as_Rule_Set.md)
- [Delete a Profile](../DataQuality/Delete_a_Profile.md)
