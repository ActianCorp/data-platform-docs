## Search Configurations

The Configurations page displays a list of all configurations.

To search for a configuration

1. Click Manage, Configurations.

    The Configurations page displays the available configurations.

2. Enter the configuration name in the Search box.

    Content will be filtered based on the search string.

    The following information is displayed on the Configurations page:

| Column Name | Description |
| --- | --- |
| Configuration | Displays the name of the configuration. Clicking the Configuration header sorts the list alphabetically in ascending or descending order.Clicking a configuration name displays details about the configuration in the Configuration Details page. See [Edit a Configuration](../DataQuality/Edit_a_Configuration.md). |
| Next Job | Provides some insight in terms of when a configuration will run. For example “On Demand” is displayed for a configuration that is run manually, and “Every 6 hours” is displayed for a configuration that is scheduled to run every six hours.See [Run a Configuration](../DataQuality/Run_a_Configuration.md) and [Edit a Configuration](../DataQuality/Edit_a_Configuration.md). |
| Owner | Displays the initials of the configuration owner’s name. Clicking on the owner icon displays the email address of the owner. |
| Status | Whether the configuration is Active (set to run on demand or by schedule) or Inactive (not set to run on demand, nor is the configuration scheduled). |
