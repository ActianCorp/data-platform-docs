## Run History

Data Profiler provides multiple views for run history. The Design environment has a run history for all profiles. The Manage environment has a run history for all configurations, and a run history for a single executed configuration.

Run history refers to profile execution results. Each time a profile is executed a job is created. The job contains the Pass/Fail results. Run history pages present aggregated job results.

Use the following run history pages to gain insight into profile execution results.

- [Run History for all Profiles](../DataQuality/Run_History_for_all_Profiles.md): Located in Design, Run History, this view provides a job status summary of all jobs executed through a profile during design time, and lists jobs executed. Use this to evaluate the overall status of executed profiles.

!!! note "Note"

    For job results for a single profile, see [View Profile Details](../DataQuality/View_Profile_Details.md).

- [Run History for all Configurations](../DataQuality/Run_History_for_all_Configurations.md): Located in Manage, Run History, this view provides a job status summary, and a list of jobs executed. Use this to evaluate the overall status of executed configurations. This page is also a starting place for managing and editing configurations.

    - [Run History for a Single Configuration](../DataQuality/Run_History_for_all_Configurations.md): Located by navigating to Manage, Run History, clicking a configuration, and then clicking Run History, this view shows all jobs executed through the selected configuration. This page provides Pass/Fail details per job, field and rule. Use this to evaluate whether results for a configuration, rule or field are improving, worsening, or remaining the same.
