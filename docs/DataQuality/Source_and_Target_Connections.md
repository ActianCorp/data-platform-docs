## Source and Target Connections

!!! note "Note"

    Before reading this topic, ensure that you have read [Creating a Data Profile](../DataQuality/Creating_a_Data_Profile.md) and [Creating a Connection](../DataQuality/Creating_a_Connection.md).

This topic provides links to connection details for source and target connectors.

If you’re [Creating a Data Profile](../DataQuality/Creating_a_Data_Profile.md) or [Creating a Connection](../DataQuality/Creating_a_Connection.md) refer to the Source Detailssection for the connector of interest. All required information is provided to [Define Source](../DataQuality/Define_Source.md) and [Define Targets](../DataQuality/Define_Targets.md). Target connection details are provided for the Actian Warehouse connector.

The following connectors are supported:

| Connector | Source/Target |
| --- | --- |
| [Actian Warehouse](../DataQuality/Actian_Warehouse.md) | Both |
| [Actian Ingres](../DataQuality/Actian_Ingres.md) | Source |
| [Actian Vector](../DataQuality/Actian_Vector.md) | Source |
| [Actian X](../DataQuality/Actian_X.md) | Source |
| [Amazon S3 (Delimited Files)](../DataQuality/Amazon_S3_(Delimited_Files).md) | Source |
| [Azure Blob Storage (Delimited Files)](../DataQuality/Azure_Blob_Storage_(Delimited_Files).md) | Source |
| [Google Cloud Storage (Delimited Files)](../DataQuality/Google_Cloud_Storage_(Delimited_Files).md) | Source |
| [NetSuite](../DataQuality/NetSuite.md) | Source |
| [Oracle CRM on Demand](../DataQuality/Oracle_CRM_on_Demand.md) | Source |
| [Salesforce](../DataQuality/Salesforce.md) | Source |
| [ServiceNow](../DataQuality/ServiceNow.md) | Source |
