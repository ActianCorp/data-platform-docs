## Export All Queries from Saved Queries or Query History

You may export all queries from the Saved Queries list as well as your Query History to a Zip file on your local system. Follow the appropriate procedure below.

To export all saved queries

1. On the left, click the Saved Queries link.

    The Saved Queries dialog opens.

2. Click the Export All Query icon:

![](images/QueryEditor_ExportQueryIcon.png)

    The Opening dialog box appears.

3. Select whether to open or save the .zip file and click OK.

    The zipped queries are saved to your local system.

To export all queries in Query History

1. On the left, click the Query History link.

    The Query History dialog opens.

2. Click the Export All Query icon:

![](images/QueryEditor_ExportQueryIcon.png)

    The Opening dialog box appears.

3. Select whether to open or save the .zip file and click OK.

    The zipped queries are saved to your local system.
