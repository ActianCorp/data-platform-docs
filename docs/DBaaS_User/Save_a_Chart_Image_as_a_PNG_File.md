## Save a Chart Image as a PNG File

AWS AV-1 and Azure only: To save a chart image

1. Create the chart type of your choice:

    - [Display a Line Chart](../DBaaS_User/Display_a_Line_Chart.md)

    - [Display a Horizontal Bar Chart](../DBaaS_User/Display_a_Horizontal_Bar_Chart.md)

    - [Display a Vertical Bar Chart](../DBaaS_User/Display_a_Vertical_Bar_Chart.md)

    - [Display a Scatterplot Chart](../DBaaS_User/Display_a_Scatterplot_Chart.md)

    - [Display a Pie Chart](../DBaaS_User/Display_a_Pie_Chart.md)

    - [Display a Vertical Stacked Bar Chart](../DBaaS_User/Display_a_Vertical_Stacked_Bar_Chart.md)

    - [Display a Horizontal Stacked Bar Chart](../DBaaS_User/Display_a_Horizontal_Stacked_Bar_Chart.md)

2. On the displayed chart pane, click the Save chart image icon:

    ![](images/QuerySaveChartImageIcon.png)

    The Opening dialog appears.

3. Select whether to open or save the file.
4. Click OK.

    The file is opened in the selected application or saved to disk in the chosen format.
