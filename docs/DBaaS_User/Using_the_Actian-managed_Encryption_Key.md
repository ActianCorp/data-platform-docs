## Using the Actian-managed Encryption Key

If you do not create an external customer-managed KMS, the default Actian-managed encryption key can set up and create a warehouse. The Actian-managed encryption key acts as your own exclusive master key ID within Actian.

You can see the use of the Actian-managed encryption key on the Database details page:

![](images/SetUpKeyManagement.png)

Warehouses you create can use the default Actian-managed encryption key until you set up your own key alias that uses your external KMS.
