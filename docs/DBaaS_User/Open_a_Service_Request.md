## Open a Service Request

Administrators may open a service request with Actian Support.

A service request is typically a maintenance task your environment requires, such as: a warehouse is stuck in a non-running state and needs to be fixed, a backup/restore operation must be scheduled, automated daily start/stop schedules need to be set, and so on.

To open a service request

1. Open the Administration interface (see [Access the Administration Interface](../DBaaS_User/Database_Administration.md)).
2. On the menu pane on the left side of the window, click Service Request.

    The Service Request page is displayed on the right.

3. Click the Open a Service Request button.

    The Create Actian CloudOps Service Request form opens in a new browser window, where you may create a case.

To view Actian health status, see Check Avalanche Health Status.
