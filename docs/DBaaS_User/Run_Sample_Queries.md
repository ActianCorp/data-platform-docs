## Run Sample Queries

The sample airline database comes with a set of queries that you can display and run on the included data.

The sample data set, which is included with every warehouse you provision, contains airline data from the U.S. Department of Transportation Bureau of Transportation Statistics (from [https://transtats.bts.gov](https://transtats.bts.gov)).

Google Cloud and AWS: To run a sample query

1. In the left pane, click the Saved Queries link.

    The Saved Queries panel opens, listing all available queries.

2. Control the display of queries by selecting Shared or Private. You also may use the Search field to narrow displayed queries.
3. Click on the query you want to open.

    The query text is displayed in the query pane.

4. Click the Run Query button.

    Results are displayed on the RESULTS tab of the bottom pane.

To export the results to a file, see [Export Query Results to a File](../DBaaS_User/Export_Query_Results_to_a_File.md).
