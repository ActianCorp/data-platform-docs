## Copy Connection Strings to the Clipboard

You can copy any of the connection strings or field contents displayed on the tools pages to the clipboard. For more information, see [Connection Tools](../DBaaS_User/Connection_Tools.md).

To copy a connection string

1. Do one of the following:

    - On the Warehouses page, click the name of the warehouse whose connection details you want to copy.

    - On the Database Instances page, click the name of the database whose connection details you want to copy.

    The Warehouse Details page or [Database Instance Details](../DBaaS_User/Database_Instance_Details.md) page is displayed.

2. Click the Connections tab.
3. Select a connection tool from the Connect to Actian Warehouse/Database dropdown (see [Connection Tools](../DBaaS_User/Connection_Tools.md)).

4. Click the copy icon at the end of the field you want to copy:

    ![](images/ConnectionToolsCopyIcon.png)

    The displayed text is copied to the clipboard.
