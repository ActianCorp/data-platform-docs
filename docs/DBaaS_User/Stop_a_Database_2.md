## Stop a Database

To stop a running database

1. On the Actian Database Instances page, identify the running database.
2. Click the status dropdown menu and select Stop Database.

    The database is stopped after a few minutes.

For more information, see [Automatic Stopping of Idle Databases](../DBaaS_User/Automatic_Stopping_of_Idle_Databases.md).
