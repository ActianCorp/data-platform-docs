## Save an Existing Query as a New Query

You can create or open a query from the following areas and save it as a new query with a unique filename:

- A query tab
- Query History

- Saved Queries

Follow this procedure to save a query to another file.

To save a query displayed in a query tab

1. Display the query in a query tab.
2. Make any desired changes.

3. Click the Save As Query icon:

    ![](images/QueryEditor_SaveAsQuery_icon.png)

4. The Save Queries dialog opens.
5. Enter a name for the query.

6. Provide any tags.
7. Select whether the query is shared or private.

8. Click Save.

The query is now available in the Saved Queries list.
