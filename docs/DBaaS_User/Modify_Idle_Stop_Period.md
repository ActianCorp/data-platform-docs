## Modify Idle Stop Period

Database administrators can modify the idle stop period.

To modify the idle stop period

1. On the Database Instances page, click the database whose idle stop period you want to change.

    The [Database Instance Details](../DBaaS_User/Database_Instance_Details.md) are displayed.

2. In the Idle Stop row, click Update.

    The Idle Stop dialog opens.

3. Set the number of hours and minutes for the new idle stop period.

!!! note "Note"

    You may not disable idle stop altogether in a non-production environment.

4. Click Update.

    The idle stop period is updated.
