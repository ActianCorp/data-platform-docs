## Concepts to Understand

## Actian Units

To provision an Actian database instance, you must specify the size of the database in terms of Actian units (AUs). An AU is a logical measure of the computing capacity of the warehouse or database.

Generally, the more AUs you specify, the faster your data loading and queries will be.

For more information about monitoring your AU usage, see Monitor AU Usage.

## Database Cost and Actian Units

If a database is running, you are charged for data storage and computing time. If your database is not running, you are charged only for data storage. After you delete a database, you are no longer charged for it. You will not be charged for any database that fails to be provisioned.

For current pricing information, see https://www.actian.com/data-platform/.

For more information about monitoring your AU usage, see Monitor AU Usage.
