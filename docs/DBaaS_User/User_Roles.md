## User Roles

The following user roles determine what users may access, manage, and administer in your company’s Actian account.

| Role | Description |
| --- | --- |
| Account Administrator | The first person to use the activation link emailed to your company’s Technical Administrator becomes the administrator of your Actian account. For more information, see Generating Your Avalanche Login Credentials.Account Administrators may administer all account warehouses as well as manage other users’ account access. They may:•Enable or disable administrative privileges for users•Activate or deactivate account users•Assign or change roles for account users |
| Warehouse Administrator | This user can create and manage, having complete access to all account warehouses in the account but cannot manage other users’ account access. |
| Warehouse User | This user may only use the Query Editor for those warehouses created by Account Administrators or Warehouse Administrators. |
| No Role | All account registrants subsequent to the Account Administrator become Actian users with no assigned role. The Account Administrator must assign a role to these users before they can view or create any warehouses. |
