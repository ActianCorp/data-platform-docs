## Display the Database Monitoring Console

To open the Monitoring console, the database you want to monitor must be running. For more information, see [Restart a Database](../DBaaS_User/Restart_a_Database_2.md).

To open the Monitoring console for a database

1. On the Database Instances page, click the name of the database you want to monitor.

    The [Database Instance Details](../DBaaS_User/Database_Instance_Details.md) page is displayed.

2. Click the Monitoring link on the left side of the page.

    The Monitoring page opens in a new browser tab, listing [Database Monitoring Services](../DBaaS_User/Database_Monitoring_Services.md) and their [Check a Service](../DBaaS_User/Check_a_Service.md).
