## Export an Open Query

You may export the query displayed in the current query tab to a file on your local system.

To export a query

1. Create, open, or display the query you want to export.
2. Click the Export Query icon:

    ![](images/QueryEditor_ExportQueryIcon.png)

    The Opening dialog box appears.

3. Select whether to open or save the .sql file and click OK.

    The query is saved to your local system.
