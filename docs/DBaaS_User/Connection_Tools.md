## Connection Tools

On the Connections panel on the Warehouse Details or [Database Instance Details](../DBaaS_User/Database_Instance_Details.md) page, the Connect to Actian Warehouse/Databse dropdown menu lists the following tools.

To copy information from the fields on the Connections tab, see [Copy Connection Strings to the Clipboard](../DBaaS_User/Copy_Connection_Strings_to_the_Clipboard.md).

| Tool | Description |
| --- | --- |
| Common Properties | Properties provided:<br>• Host<br>• Database<br>• Username<br>• JDBC/.NET Port<br>• ODBC Port (listen address)<br>• Authentication Type<br>• Authentication Server |
| ODBC Connectivity | Provides ODBC connection information. Requires the [Actian Client Runtime Package](../DBaaS_User/Actian_Client_Runtime_Package.md). |
| JDBC Connectivity | Provides JDBC connection information. Requires the [Actian JDBC Driver](../DBaaS_User/Actian_JDBC_Driver.md). If you are using JDBC driver 4.3.7 or later, switch the toggle on to update the connection string before copying. |
| Actian SQL CLI | Provides SQL Command Line Interface (Terminal Monitor) connection information. Requires the [Actian Client Runtime Package](../DBaaS_User/Actian_Client_Runtime_Package.md).For more information, see [Start the SQL CLI](../SQLLanguage/Start_the_SQL_CLI.md) and [sql Command Options and Flags](../SQLLanguage/sql_Command_Options_and_Flags.md). |
| DBeaver | Provides DBeaver connection information. Requires the [Actian JDBC Driver](../DBaaS_User/Actian_JDBC_Driver.md). If you are using JDBC driver 4.3.7 or later, switch the toggle on to update the connection string before copying.For more information, see Connect to DBeaver with JDBC. |
| DBVisualizer | Provides DBVisualizer connection information. Requires the [Actian JDBC Driver](../DBaaS_User/Actian_JDBC_Driver.md). If you are using JDBC driver 4.3.7 or later, switch the toggle on to update the connection string before copying. |
| Looker | Provides Looker connection information:<br>• Dialect<br>• Host<br>• Port<br>• Database<br>• Username<br>• Additional ParamRequires the [Actian JDBC Driver](../DBaaS_User/Actian_JDBC_Driver.md).For more information, see Connect to Looker with JDBC. |
| Power BI | Provides Power BI connection information:<br>• Connection string<br>• UsernameRequires the [Actian Client Runtime Package](../DBaaS_User/Actian_Client_Runtime_Package.md).For more information, see Connect to Power BI with ODBC. |
| Squirrel SQL | Provides Squirrel SQL connection information. Requires the [Actian JDBC Driver](../DBaaS_User/Actian_JDBC_Driver.md). If you are using JDBC driver 4.3.7 or later, switch the toggle on to update the connection string before copying. |
| Tableau | Provides Tableau connection information:<br>• Server<br>• Port<br>• Virtual node<br>• Options<br>• Database<br>• Username<br>• PasswordRequires the [Actian Client Runtime Package](../DBaaS_User/Actian_Client_Runtime_Package.md).For more information, see Connect to Tableau with ODBC. |
