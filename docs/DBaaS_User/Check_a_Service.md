## Check a Service

To check a service

On the Monitoring console page (see [Display the Database Monitoring Console](../DBaaS_User/Display_the_Database_Monitoring_Console.md)), click the name of the service you want to check.

The Service page is displayed, listing the service information (see [Database Monitoring Services](../DBaaS_User/Database_Monitoring_Services.md)).

To graph the data, click the Graph link (see Graphing Service Information).
