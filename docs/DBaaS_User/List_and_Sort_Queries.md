## List and Sort Queries

AWS AV-1 and Azure: You may list and sort saved queries.

To list and sort queries

1. On the Query Editor toolbar, click the Queries button.

    The Queries dialog appears.

2. Select your desired states from the queries, connections, and order dropdowns.
3. To further narrow the list of queries, enter text in the search field and press Enter.

4. Click to select the desired query.

    The query text is displayed in the query pane.
