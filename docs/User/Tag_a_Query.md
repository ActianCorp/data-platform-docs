## Tag a Query

You may tag a query with terms that you can later search on in the Saved Queries dialog. Follow the appropriate procedure for your cloud platform.

AWS AV-1 and Azure:To tag a query

1. Create or open the query in the query pane.

    See [Create and Save a New Query](../User/Create_and_Save_a_New_Query.md) or [Open a Saved Query](../User/Open_a_Saved_Query.md).

2. Click the Tags icon on the toolbar.

    The Query Tags dialog appears.

3. Enter one or more tags separated by commas.
4. Close the Query Tags dialog.

Google Cloud and AWS AV-2:To tag an existing query

1. In the left pane, click the Saved Queries link.

    The Saved Queries panel opens, listing all available queries.

2. Control the display of queries by selecting Shared or Private. You also may use the Search field to narrow displayed queries.
3. For the query you want to tag, click the Edit Query Properties icon: ![](images/QueryEditor_EditQueryProperties_button.png)

    The Edit Query dialog opens in the panel.

4. Enter one or more tags separated by commas.
5. Click the Update button to save your changes.
