## Spark Connect Server UI

The Spark Connect Server UI allows you to monitor and manage Spark jobs executed through the Spark Connect Server.

| Capability | Description |
| --- | --- |
| Execution monitoring | Displays all executed items, including their logical and physical plans. |
| Plan metrics | Shows metrics associated with each execution plan. |
| Issue diagnosis | Surfaces job-level details, such as out-of-memory errors and task counts to help you troubleshoot workloads. |

!!! note "Note"

    Use this UI alongside Spark Logs, which you can filter by time range and component to support your experimentation and debugging workflows.
