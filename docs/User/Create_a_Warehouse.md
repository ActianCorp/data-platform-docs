# Create a Warehouse

For information about Actian units and warehouse cost, see [Concepts to Understand](../User/Concepts_to_Understand.md).

For AWS AV-1 and Azure, it takes 20 minutes or longer to create a warehouse, depending on its size. For Google Cloud and AWS AV-2, it takes about 5 minutes.
