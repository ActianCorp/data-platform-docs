## Actian Data Platform Features

- Fully managed – Reduces administration costs and implementation time.
- Highly secure – Enterprise firewalls, intrusion detection, SIEM logging, SOC2 compliance, authentication integration, security patching, and many others. For more information about security, see the Security Guide.

- JSON support – Parse and import JSON documents. Work with semi-structured data within a relational database with ease. For more information, see the SQL Language Guide and the Data Loading Guide.
- User-defined function support – Perform database operations that are not available through built-in, system-defined functions. Build customized SQL, JavaScript, and Python code that runs alongside supported SQL queries. For more information, see the SQL Language Guide.

- Extensive SQL support – Standard ANSI SQL enables the use of existing SQL without rewrite. For more information, see the SQL Language Guide.
- Seamless integration – Provides comprehensive integration capabilities to SaaS applications such as Salesforce, NetSuite, and Marketo.

- Open – Offers industry standard data access, including support for Spark, ODBC, JDBC, and .NET. For more information, see the Connectivity Guide.
- Interoperability – Delivers extensive interoperability with legacy on-premises and native cloud apps as well as ETL and BI tools.
