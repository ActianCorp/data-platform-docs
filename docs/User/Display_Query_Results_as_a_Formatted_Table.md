## Display Query Results as a Formatted Table

To display query results as a formatted table

1. Run your query to display the results in the query results pane (see [Run Your Own Queries](../User/Run_Your_Own_Queries.md) or [Run Sample Queries](../User/Run_Sample_Queries.md)).
2. In the top row of the results table, click the table link:

    ![](images/QueryTableLink.png)

    ![](images/ExpandResults_GCP.png)

    The formatted table is opened in a new browser tab or window.
