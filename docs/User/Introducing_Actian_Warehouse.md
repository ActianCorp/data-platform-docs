# Introducing Actian Warehouse

## Overview of Actian Warehouse on the Actian Data Platform

Actian Warehouse on the Actian Data Platform (hereafter Actian Warehouse) is a fully managed cloud data warehouse service designed to deliver high performance and scale across all dimensions—data volume, concurrent users, and query complexity—at a fraction of the cost of alternative solutions.

Actian Warehouse is a web-based application that can be deployed on multiple clouds, including Amazon Web Services (AWS), Microsoft Azure, and Google Cloud, enabling you to migrate or offload applications and data to the cloud at your own pace. With Actian Warehouse, you use data warehouses in the cloud without having to deal with software, hardware, and all the associated monitoring.
