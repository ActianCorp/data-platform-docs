# Administrate Warehouses

If a warehouse is running, you are charged for data storage and computing time. If your warehouse is not running, you are charged only for data storage. You may want to stop a warehouse when it is not being used.

Idle AWS and Azure warehouses automatically stop after a minimum of 60 minutes of no query activity.
