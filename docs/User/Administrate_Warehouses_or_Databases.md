# Administrate Warehouses or Databases

If a warehouse or database is running, you are charged for data storage and computing time. If your warehouse/database is not running, you are charged only for data storage. You may want to stop a warehouse/database when it is not being used.

Idle AWS and Azure warehouses automatically stop after a minimum of 60 minutes of no query activity.
