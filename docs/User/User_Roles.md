## User Roles

The following user roles determine what users may access, manage, and administer in your company’s Actian Data Platform account.

| Role | Description |
| --- | --- |
| Account Administrator | The first person to use the activation link emailed to your company’s Technical Administrator becomes the administrator of your Actian Data Platform account. For more information, see [Generating Your Platform Login Credentials](../User/Generating_Your_Platform_Login_Credentials.md).Account Administrators may administer all account warehouses as well as manage other users’ account access. They may:<br>• Enable or disable administrative privileges for users<br>• Activate or deactivate account users<br>• Assign or change roles for account users |
| Warehouse Administrator | This user can create and manage, having complete access to all account warehouses in the account but cannot manage other users’ account access. |
| Warehouse User | This user may only use the Query Editor for those warehouses created by Account Administrators or Warehouse Administrators. |
| No Role | All account registrants subsequent to the Account Administrator become Actian Data Platform users with no assigned role. The Account Administrator must assign a role to these users before they can view or create any warehouses. |
