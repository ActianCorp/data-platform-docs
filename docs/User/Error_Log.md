## Error Log

Displays error log messages from errlog.log and vectorwise.log files. Each service check invocation displays error messages generated since the previous service check.

The detail section displays each error message. For example:

```
2020-06-11 09:04:25.273548 PID 27672:TID 140574727390976:SID 87:TXID 1970:ERROR:VALUE_SPACE:value_space_append_modifies: out of memory
```
