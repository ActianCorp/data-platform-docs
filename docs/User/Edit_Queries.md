## Edit Queries

Auto-complete

As you type query text, auto-complete entries appear. You may select the highlighted entry by pressing Enter.

Context menu

When you click within words or select them, all matching words are highlighted throughout the query. Right-clicking the mouse displays a context menu with these commands:

| Command | Description |
| --- | --- |
| Change All Occurrences (Ctrl+F2) | Places multiple cursors at the ends of all occurrences of the word.You may use the right and left arrow keys to position the cursor or backspace and then replace the text in all occurrences.Pressing Ctrl+F2 selects all occurrences of the selected word. |
| Cut | Cuts the selected text from the query. |
| Copy | Copies the selected text from the query. |
| Command Palette (F1) | Opens the Command Palette pop-up.•Scroll through the commands to find the one you want to execute.•Enter text in the search field to narrow the list to pertinent commands.•Keyboard shortcuts are displayed for some commands.•If the cursor is inserted in query text, you may use F1 to open the Command Palette.For a complete list of commands, see [Command Palette Reference](../User/Command_Palette_Reference.md). |
