# Monitor Warehouses

The Actian Data Platform Monitoring console lets you display and graph service statistics about the following warehouse information:

- Active queries
- Connected sessions

- Error log
- Pending disk updates

- Query parallelism
- System data skew

- Table data skew
- Warehouse disk usage

For more information about these services, see [Warehouse Monitoring Services](../User/Warehouse_Monitoring_Services.md).

!!! note "Note"

    If you use Azure Private Link, you cannot use the warehouse monitoring facility because it relies on a public DSN name. For more information, see Azure Private Link Limitations.
