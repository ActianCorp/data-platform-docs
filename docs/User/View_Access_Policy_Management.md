## View Access Policy Management

Access policies define user roles for warehouse users. There are two types of users:

- Warehouse User
- Warehouse Administrator

Access policies can be global or not.

To view access policies

1. Open the Administration interface (see [Access the Administration Interface](../User/Warehouse_Administration.md)).
2. In the pane on the left, click Access Policy Management.

    The Access Policy Management page is displayed on the right.

3. Click the Access Policy Name you want to examine.

    The Access Policy Details dialog opens, displaying:

    - The policy name (for example, “Warehouse User”)

    - A short description

    - The JSON permissions code for the user policy
