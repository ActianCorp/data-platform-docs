## User Profiles

Actian Data Platform supports the following user profiles:

**useradmin**

:   Allows any user with this profile to create and delete new users or update existing users

**user**

:   Has no privilege to maintain users

Users with any profile can change their own password—see [ALTER USER](../SQLLanguage/ALTER_USER.md).
