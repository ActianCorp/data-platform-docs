## Display the Warehouse Monitoring Console

To open the Monitoring console, the warehouse you want to monitor must be running. For more information, see [Restart a Warehouse](../User/Restart_a_Warehouse.md).

To open the Monitoring console for a warehouse

1. On the Warehouses page, click the name of the warehouse you want to monitor.

    The [Warehouse Details](../User/Warehouse_Details.md) page is displayed.

2. Click the Monitoring link on the left side of the page.

    The Monitoring page opens in a new browser tab, listing [Warehouse Monitoring Services](../User/Warehouse_Monitoring_Services.md) and their [Service Statuses](../User/Service_Statuses.md).
