## Download a Chart as a PNG File

You can download a graphical snapshot of a service chart at any time using the Download Plot feature. The file is saved as a PNG graphic.

To download a chart as a PNG file

1. Display the service data as a chart (see [Graphing Service Information](../User/Graphing_Service_Information.md)).
2. On the Graph tab, click the Download plot as a png icon:

    ![](images/DownloadPlotPNGToolIcon.png)

    The Opening dialog appears.

3. Choose to open or save the file, then click OK.

The chart is either opened in the application you selected or saved to disk.
