## Connection Tools

On the Connections panel on the [Warehouse Details](../User/Warehouse_Details.md) or [Database Instance Details](../User/Database_Instance_Details.md) page, the Connect to Actian warehouse/Database dropdown menu lists the following tools.

To copy information from the fields on the Connections tab, see [Copy Connection Strings to the Clipboard](../User/Copy_Connection_Strings_to_the_Clipboard.md).

| Tool | Description |
| --- | --- |
| Common Properties | Properties provided:•Host•Database•Username•JDBC/.NET Port•ODBC Port (listen address)•Authentication Type•Authentication Server |
| ODBC Connectivity | Provides ODBC connection information. Requires the [Actian Client Runtime Package](../User/Actian_Client_Runtime_Package.md). |
| JDBC Connectivity | Provides JDBC connection information. Requires the [Actian JDBC Driver](../User/Actian_JDBC_Driver.md). If you are using JDBC driver 4.3.7 or later, switch the toggle on to update the connection string before copying. |
| Actian SQL CLI | Provides SQL Command Line Interface (Terminal Monitor) connection information. Requires the [Actian Client Runtime Package](../User/Actian_Client_Runtime_Package.md).For more information, see [Start the SQL CLI](../SQLLanguage/Start_the_SQL_CLI.md) and [sql Command Options and Flags](../SQLLanguage/sql_Command_Options_and_Flags.md). |
| DBeaver | Provides DBeaver connection information. Requires the [Actian JDBC Driver](../User/Actian_JDBC_Driver.md). If you are using JDBC driver 4.3.7 or later, switch the toggle on to update the connection string before copying.For more information, see [Connect to DBeaver with JDBC](../User/Connect_to_DBeaver_with_JDBC.md). |
| DBVisualizer | Provides DBVisualizer connection information. Requires the [Actian JDBC Driver](../User/Actian_JDBC_Driver.md). If you are using JDBC driver 4.3.7 or later, switch the toggle on to update the connection string before copying. |
| Looker | Provides Looker connection information:•Dialect•Host•Port•Database•Username•Additional ParamRequires the [Actian JDBC Driver](../User/Actian_JDBC_Driver.md).For more information, see [Connect to Looker with JDBC](../User/ConnectLookerJDBC.md). |
| Power BI | Provides Power BI connection information:•Connection string•UsernameRequires the [Actian Client Runtime Package](../User/Actian_Client_Runtime_Package.md).For more information, see [Connect to Power BI with ODBC](../User/ConnectPowerBIODBC.md). |
| Squirrel SQL | Provides Squirrel SQL connection information. Requires the [Actian JDBC Driver](../User/Actian_JDBC_Driver.md). If you are using JDBC driver 4.3.7 or later, switch the toggle on to update the connection string before copying. |
| Tableau | Provides Tableau connection information:•Server•Port•Virtual node•Options•Database•Username•PasswordRequires the [Actian Client Runtime Package](../User/Actian_Client_Runtime_Package.md).For more information, see [Connect to Tableau with ODBC](../User/ConnectTableauODBC.md). |
