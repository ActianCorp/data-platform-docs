## Get Connection Properties for DBeaver

To connect to your warehouse, you must provide DBeaver with a JDBC URL and a username (the default user is dbuser).

To get connection properties for DBeaver

1. On the Warehouses page, click the name of the warehouse whose password you want to change.

    The [Warehouse Details](../User/Warehouse_Details.md) page is displayed.

2. Click the Connections tab.
3. From the Connect to Actian warehouse dropdown, select DBeaver.

    Connection information for the tool is displayed.

4. Copy the JDBC URL by clicking the copy button at the right of the field:
