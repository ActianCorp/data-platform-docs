# Grant Access to Warehouse or Database for External Tables Access

The Actian Data Platform requires access to your cloud storage account to load data using the external tables method (for more information, see [Data Loading Overview](../DataLoading/DataLoadingOverview.md) in the Data Loading Guide).

Part of configuring a warehouse is setting authentication credentials and connection information for external table access. You do this on the [Warehouse Details](../User/Warehouse_Details.md) page or [Database Instance Details](../User/Database_Instance_Details.md) page.

!!! note "Note"

    Setting connection access while data loading is in progress may interrupt the loading operation.

For information about creating cloud account storage and generating IAM access keys, see [Set Up Access Credentials for Cloud Storage Accounts](../User/Set_Up_Access_Credentials_for_Cloud_Storage_Acco.md).
