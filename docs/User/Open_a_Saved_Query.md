## Open a Saved Query

You open any existing saved query from the Saved Queries dialog. Follow the appropriate procedure for your cloud platform.

AWS AV-1 and Azure:To open a saved query

1. On the Query Editor toolbar, click the Queries button.

    The Queries dialog appears.

2. Control the display of queries by setting query sharing, connections, or save order dropdowns. You may also use the search or tags fields to narrow displayed queries.
3. Click on the query you want to open.

    The query text is displayed in the query pane.

Google Cloud and AWS AV-2:To open a saved query

1. In the left pane, click the Saved Queries link.

    The Saved Queries panel opens, listing all available queries.

2. Control the display of queries by selecting Shared? or Private?. You also may use the Search field to narrow displayed queries.
3. Click on the query you want to open.

    The query text is displayed in the query pane.
