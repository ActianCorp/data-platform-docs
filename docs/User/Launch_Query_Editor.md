## Launch Query Editor

To launch Query Editor, you must be the creator of the warehouse or be added as a warehouse user. For more information, see [How Authentication Works](../User/How_Authentication_Works.md) and [User Roles](../User/User_Roles.md).

To launch Query Editor

1. On the Warehouses or Database Instances page, click the name of the warehouse or database you want to access in Query Editor.

    The [Warehouse Details](../User/Warehouse_Details.md) page or [Database Instance Details](../User/Database_Instance_Details.md) page is displayed.

2. On the left side of the window, click the Query Editor link.

    Query Editor opens in a new browser tab.

For a labeled illustration of Query Editor, see [Query Editor Diagram](../User/Query_Editor_Diagram.md) for your cloud platform.
