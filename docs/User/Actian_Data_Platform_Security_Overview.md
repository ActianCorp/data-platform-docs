## Actian Data Platform Security Overview

Protecting your data is fundamental to doing business today. You can trust your data with the Actian Warehouse. Delivering robust security is a core aspect of Actian’s design principles. The Actian Data Platform delivers advanced security at cloud service levels.

As part of the [Cloud Security Alliance](https://cloudsecurityalliance.org/), the Actian Data Platform continuously adopts best practices to ensure secure cloud computing. The Actian Data Platform follows strict policies encompassing the security, availability, processing, integrity, and confidentiality of your data, enabling SOC2 compliance upon request (see [SOC2 Security Attestation Available](../Security/SOC2_Security_Attestation_Available.md)).

provides:

- Disk-level data at rest encryption, columnar encryption, and encryption in transit
- Dynamic data masking, ensuring that sensitive data is not seen by the user while no physical change to the original data takes place

- VPC isolation—the data plane is separated from the management plane; each warehouse is only accessible through user-specified IP addresses and can also be isolated from the public Internet
- Discretionary access control only enables direct access to the warehouse by requiring an IP allow list as well as database authentication

For more information about these security features, see the Security Guide.
