## Actian Data Platform Security Features

Data security is a concern for everyone. The need to ensure the safety of personal information and to protect vital corporate assets stored electronically is of paramount importance.

Actian Data Platform has a built-in hierarchical security system that any privileged user can use to fully control access to the database.

Security in Actian Data Platform is provided through the following features:

- User-related security features, including:

    - –Users

    - –Groups

    - –Roles

    - –Profiles

    - –Subject privileges

- Object permissions
- Security alarms (enabled on request by contacting [Actian Support](https://supportservices.actian.com/support-services/support/#contacts))

- Data at rest encryption
