## Object Permissions

Data access can be restricted through the granting of permissions on objects. Permissions can be granted on the following objects: database, table, view, procedure, database event, role, and current installation. For more information, see [Object Permissions (Grants)](../Security/Object_Permissions_(Grants).md).
