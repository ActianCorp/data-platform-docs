## Subject Privileges

Subject privileges define the operations a user can perform and are assigned to a user or a role. Subject privileges include:

- [MAINTAIN_USERS Privilege](../Security/Assigning_Privileges_and_Granting_Permissions.md)
- SECURITY Privilege

- Trace Privilege
