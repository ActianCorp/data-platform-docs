## Managing Configurations

Configurations are a set of properties and parameters that specify when, where, and how an integration will be executed. Configurations contain references to a specific integration, the location in which the integration will be executed, and the frequency in which executions will occur.

You can create configurations manually or through Templates (see [Creating Templates](../Integrations/Creating_Templates.md), [Managing Templates](../Integrations/Managing_Templates.md), and [Create a Configuration from Template](../Integrations/Manage_Template_Macros.md)). Using templates makes managing multiple configurations simpler.

All your Configurations are displayed on the Configurations page. You can open this page by clicking Integrations, Manage, Configurations and perform the following actions:

- [View Configurations](../Integrations/View_Configurations.md)
- [Edit Configuration Details](../Integrations/Edit_Configuration_Details.md)

- [Run a Configuration Manually](../Integrations/Run_a_Configuration_Manually.md)
- [Run Configuration with a Message](../Integrations/Run_Configuration_with_a_Message.md)

- [Run Configuration with a File](../Integrations/Run_Configuration_with_a_File.md)
- [Duplicate a Configuration](../Integrations/Duplicate_a_Configuration.md)

- [Set a Configuration to Active or Inactive](../Integrations/Set_a_Configuration_to_Active_or_Inactive.md)
- [Set a Configuration as a Favorite](../Integrations/Set_a_Configuration_as_a_Favorite.md)

- [Delete a Configuration](../Integrations/Delete_a_Configuration.md)
- [Import Integration](../Integrations/Import_Integration.md)

- [Edit Configuration Schedule](../Integrations/Edit_Configuration_Schedule.md)
- [View Configuration Jobs](../Integrations/View_Configuration_Jobs.md)
