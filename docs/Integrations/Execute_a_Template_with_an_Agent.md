## Execute a Template with an Agent

You can set a template to execute using an agent.

To set a template to execute with/without an agent

1. Click Integrations, Manage, Templates.

    The Templates page is displayed.

2. Click the template you want to edit.
3. To execute with an agent, set the Run Location to User Agent.

    To execute without an agent, set the Run Location to Default.

For more information, see [View Templates](../Integrations/View_Templates.md).
