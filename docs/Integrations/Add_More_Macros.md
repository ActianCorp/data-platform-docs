## Add More Macros

If you have not yet created any macros, go to [Add Your First Macro](../Integrations/Add_Your_First_Macro.md).

To add more public macro

1. Click Integrations, Manage, Macros.

    The Macros page displays the available macros.

2. Click the Add Macro button.
3. Specify the following:

    - Macro – Name of the macro

    - Value – Value for the macro.

**IMPORTANT!**If required, encrypt the macro value by clicking![](images/UnlockIcon.png)(Secure Macroicon). Secured macros cannot be unsecured, and their values cannot be edited. If you need to change the value of a secured macro, you must delete and readd it.

    - Description – Brief description of the macro
