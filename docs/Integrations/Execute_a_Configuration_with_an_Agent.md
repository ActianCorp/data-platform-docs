## Execute a Configuration with an Agent

You can set a configuration to execute using an agent.

To set a configuration to execute with/without an agent

1. Click Integrations, Manage, Configuration.

    The Configuration page is displayed.

2. Click on the configuration you want to run with an agent.

    The Configuration Details page is displayed.

3. To execute with an agent, set the Run Location to User Agent.

    To execute without an agent, set the Run Location to Default.

For more information, see [Edit Configuration Details](../Integrations/Edit_Configuration_Details.md).
