## Agile CRM

Agile CRM is a CRM software with sales and marketing automation. This is a rest-based connector which retrieves data from your Agile CRM application.

- [Prerequisites](../Integrations/Agile_CRM.md)
- [Connection Details](../Integrations/Agile_CRM.md)

- [Additional Information](../Integrations/Agile_CRM.md)

Prerequisites

You must have an Agile CRM account.

Connection Details

Specify the following details to define a connection:

| Property | Description |
| --- | --- |
| Agile account mail ID | The user mail ID. |
| Base URL | You account URL. For example:`https://{domain}.agilecrm.com/dev` |
| Rest API Key | The Rest API key can be obtained from your Agile Account. |

Additional Information

API docs can be found at [https://github.com/agilecrm/rest-api](https://github.com/agilecrm/rest-api).
