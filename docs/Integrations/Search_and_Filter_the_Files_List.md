## Search and Filter the Files List

To search and filter files

- To view uploaded files, click Integrations, Manage, Files.
- To sort the list, click File Name, Last Modified(PDT) or File Size column header.

- In the Private Files view, to display files for a particular account user you can select the user name from the dropdown.
- To search on information in any of the fields, click the ![](images/SearchIcon.png) icon, type your text and click Enter.

- To reduce or enlarge the files list or jump to earlier or later pages of the listing, click the appropriate control on the toolbar at the end of the file list:
