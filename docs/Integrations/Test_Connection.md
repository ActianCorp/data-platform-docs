## Test Connection

You can test connections from the following two places:

- When creating a new connection. See [Create Connections](../Integrations/Create_Connections.md).
- When editing a connection. See [Test Connection](../Integrations/Test_Connection.md).

To test a connection

1. Click Integrations, Connections.

    The Connections page displays the available connections.

2. Select the check box that is displayed for the connection that you want to test, then click ![](images/DesignWorkspace_111.png).

    The Edit Existing Connection page is displayed. By default, the focus is on the Define Properties page.

3. Review the connection properties and change it if required. See [Source and Target Connections](../Integrations/Source_and_Target_Connections.md).

!!! note "Note"

    If the connection type is Actian Warehouse, it must be running in order to connect to it while testing a connection.

4. Click Test.

    If connection is successful, you will receive a success message. If connection fails, an appropriate error message is displayed.

5. After a successful test, click Save.

    You will be redirected to the Connections page.
