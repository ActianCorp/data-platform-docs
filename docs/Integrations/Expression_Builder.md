## Expression Builder

Expression builder is an intuitive visual code builder that brings the power of a scripting language to non-technical users. It consists of interlocking, graphical blocks that represent code concepts like text, mathematical, logical, and date time functions. It allows users to build small and simple expressions without worrying about syntax of a scripting language.

![](images/DesignWorkspace_46.png)

The expressions that you build using Expression Builder can be included in your integration. See [Mapping](../Integrations/Mapping.md). The expressions when evaluated will produce the required result.
