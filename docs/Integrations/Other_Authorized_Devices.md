## Other Authorized Devices

The Other Authorized Devices list is visible to administrators. Items listed are typically file folder listeners, but can be anything that has been set up via Device Flow.

To view the list of Other Authorized Devices

Click Integrations, Manage, Agents & Devices to view the Agents and Devices page. The Other Authorized Devices list appears below the list of Registered Agents.

- To search for specific text within the Other Authorized Devices list, click the ![](images/SearchIcon.png) icon and enter the text you want to search on. The device names that match the text you enter automatically display.
- To sort the listed devices in ascending or descending alphabetical order, click the Hostname or Client Type column header.

- To reduce or enlarge the Agents list or jump to earlier or later pages of the listing, click the appropriate control on the toolbar at the end of the list:

![](images/RuntimeWorkspace_128.png)

| Column Name | Description |
| --- | --- |
| Hostname | Hostname of owner of the agent. Clicking on the Hostname column header sorts the list of agents in ascending or descending alphabetical order. |
| Client Type | Displays the type of client. Clicking on the Client Type column header sorts the list of agents in ascending or descending alphabetical order. |
| Owner | Displays the initials of the device owner. |
| ![](images/cogwheelIcon.png) | Click the Remove button to remove the device from the list. |
