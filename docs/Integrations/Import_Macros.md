## Import Macros

To import a public macro file

1. Click Integrations, Manage, Macros.

    The Macros page displays the available macros.

2. Click the ![](images/RuntimeWorkspace_117.png) icon on the Add Macro button and select Import Macros.

    The Upload Macro File dialog is displayed.

3. Drag and drop the file that contains the macros or click the Browse File link to specify the file.
4. Click Done.

    The macros are imported and displayed int the Macros list.
