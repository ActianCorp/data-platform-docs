## Delete a Configuration

To delete a configuration

1. Click Integrations, Manage, Configurations.

    The Configurations page lists the available configurations. See [View Configurations](../Integrations/View_Configurations.md).

2. Do one of the following:

    - Click the down arrow on the Run button that is displayed for the configuration that you want to delete, and select Delete.

    - Click the configuration name that you want to delete and go to the Configuration Details page, click the down arrow icon on the Run Configuration button, and select Delete Configuration.

    The Delete Configuration dialog opens.

3. Click Delete.

    The selected configuration is deleted and no longer appears on the Configurations page.
