## Block Categories

The following table lists the different block categories.

| Block Category | Description |
| --- | --- |
| Fields | Lists the Source block that can be used in block expressions to insert the value from the selected source field. The “field” drop-down of this block is automatically populated with the available source fields.Example:![](images/DesignWorkspace_55.png)This block represents the value of “Field1”.Script:`@Field1` |
| Text | Lists blocks that represent text functions. See [List of Text Blocks](../Integrations/List_of_Text_Blocks.md) |
| Math | Lists blocks that represent mathematical functions. See [List of Math Blocks](../Integrations/List_of_Math_Blocks.md). |
| Convert | Lists blocks that represent convert functions. See [List of Convert Blocks](../Integrations/List_of_Convert_Blocks.md). |
| Date/Time | Lists blocks that represent date/time functions. See [List of Date/Time Blocks](../Integrations/List_of_Date_2fTime_Blocks.md) |
| Logic | Lists blocks that represent logical functions. See [List of Logic Blocks](../Integrations/List_of_Logic_Blocks.md) |
