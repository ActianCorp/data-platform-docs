## Mailchimp

The Mailchimp Connector allows you to access the data within your Mailchimp applications.

- [Prerequisites](../Integrations/Mailchimp.md)
- [Connection Details](../Integrations/Mailchimp.md)

- [Additional Information](../Integrations/Mailchimp.md)

Prerequisites

You must have a Mailchimp account.

Connection Details

Specify the following details to define a connection:

| Property | Description |
| --- | --- |
| Username | The Mailchimp username used to login to the application. |
| Password | The Mailchimp password which is the API key received from Mailchimp. |
| Base URL | The Mailchimp Base URL, for example:`https://<dc>.api.mailchimp.com/3.0`where the '3.0' is the current API version. |

Additional Information

Please refer to the Mailchimp API documentation for more information on the API requests and responses. API docs can be found at [https://mailchimp.com/developer/marketing/api/](https://mailchimp.com/developer/marketing/api/).
