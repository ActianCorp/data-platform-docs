## Delete Files

If you are the owner of private files in your Files list, you can delete them. Only administrators can delete public files.

To delete files

1. Click Integrations, Manage, Files.
2. Select the file(s) you want to delete.

3. Click the Delete File button that appears.

    The selected file is deleted.
