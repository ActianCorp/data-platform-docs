## Hive

The Hive connector enables you to manage the project management and collaboration platform that helps teams plan, execute, and track projects efficiently with features like task management, messaging, and analytics. It provides a centralized workspace to streamline workflows and improve productivity.

- [Prerequisites](../Integrations/Hive.md)
- [Connection Details](../Integrations/Hive.md)

- [Additional Information](../Integrations/Hive.md)

Prerequisites

You must have a Hive account.

Connection Details

The connector authenticates with the Hive service using an API Key.

Specify the following details to define a connection:

| Property | Description |
| --- | --- |
| Base URL | The base URL for accessing the APIs must be specified:`https://app.hive.com` |
| API Key | The API Key must be generated. |

Additional Information

Please refer to the documentation for setting up the credentials. Authentication documentation can be found at [https://developers.hive.com/reference/api-keys-and-auth](https://developers.hive.com/reference/api-keys-and-auth).
