## Set a Template to Active or Inactive

!!! warning "Important"

    **IMPORTANT!**Setting a template to Inactive not only inactivates the template but will deactivate any configurations based on it.

There are two ways to set a template as Active or Inactive:

- From the Templates page (see [View Templates](../Integrations/View_Templates.md))
- From the Template Details page (see [Edit Template Details](../Integrations/Edit_Template_Details.md))

Follow the appropriate procedure below.

To set a template to Active or Inactive from the Templates page

1. Click Integrations, Manage, Templates.

    The Templates page is displayed, listing all available templates. The Active column indicates whether the template is currently Active or Inactive.

2. Select the check box that is displayed against the template name that you want to set as Active or Inactive.

    The Choose an action button is displayed.

3. To set an Active template to Inactive, from the Choose an action drop-down menu, select Inactive.

    The Active column shows Inactive for the template.

4. To set an Inactive template to Active, from the Choose an action drop-down menu, select Active.

    The Active column shows Active for the template.

To set a template to Active or Inactive from its Template Details page

1. Click Integrations, Manage, Templates.

    The Templates page is displayed, listing all available templates.

2. Click the name of the template you want to set as Active or Inactive.

    The Template Details page is displayed.
