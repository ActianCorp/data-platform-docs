## Overview of the Design Environment

Use the Design environment to create, edit, copy, delete, and test integrations, connections and services. You can also execute integrations and view the execution results.

You can read data from Actian Warehouse, Salesforce, ServiceNow, NetSuite, and others (see [Source and Target Connections](../Integrations/Source_and_Target_Connections.md) for a complete list), and write the data to any Actian Warehouse table.

Summary of what users can do in the Design environment:

- Create a connection. See [Create Connections](../Integrations/Create_Connections.md) and [Test Connection](../Integrations/Test_Connection.md). See also:

    - [Source and Target Connections](../Integrations/Source_and_Target_Connections.md)

    - [Define Source](../Integrations/Define_Source.md)

- Create an integration. See [Creating Integrations](../Integrations/Creating_Integrations.md). See also:

    - [Define Source](../Integrations/Define_Source.md)

    - [Define Target](../Integrations/Define_Target.md)

    - [Mapping](../Integrations/Mapping.md)

    - [Mapping Hierarchical Sources](../Integrations/Mapping_Hierarchical_Sources.md)

- Execute an integration. There are three ways to execute an Integration:

    - When [Creating Integrations](../Integrations/Creating_Integrations.md) - When creating an integration, as an end step, you can choose to Save & Run an integration.

    - By scheduling an integration - When creating an integration, as an end step, you can choose to Save & Schedule it. Thus you can create a schedule for integration execution. See also [Edit Integration Schedule](../Integrations/Edit_Integration_Schedule.md).

    - Run an Integration manually (without a schedule):

        - –From the integration editor. See [Creating Integrations](../Integrations/Creating_Integrations.md).

        - –From the Integration Designs page. See [Search Integrations](../Integrations/Search_Integrations.md).

        - –From the integration details page. See [View Integration Details](../Integrations/View_Integration_Details.md).

- When an integration run is completed, runtime metrics will be available for review. See [View Integration Run History](../Integrations/View_Integration_Run_History.md).
- Edit an integration. See [Edit Integration](../Integrations/Edit_Integration.md). See also [Managing Integrations](../Integrations/Managing_Integrations.md).

- Create and manage a service. See [Create a Service](../Integrations/Create_a_Service.md), [Import a Service](../Integrations/Import_a_Service.md), [Edit a Service](../Integrations/Edit_a_Service.md), and [Delete a Service](../Integrations/Delete_a_Service.md). See also [Endpoints](../Integrations/Endpoints.md).
