## Managing Integrations

!!! note "Note"

    For information on creating new Integrations, see [Creating Integrations](../Integrations/Creating_Integrations.md).

All your integrations are listed on the Integration Designs page. You can open the Integration Designs page by clicking Integrations. You can select a listed integration and perform the following actions:

- [Search Integrations](../Integrations/Search_Integrations.md)
- [View Integration Details](../Integrations/View_Integration_Details.md)

- [Edit Integration](../Integrations/Edit_Integration.md)
- [Duplicate Integration](../Integrations/Duplicate_Integration.md)

- [Delete Integration](../Integrations/Delete_Integration.md)
- [Edit Integration Schedule](../Integrations/Edit_Integration_Schedule.md)

- [Run an Integration Manually](../Integrations/Run_an_Integration_Manually.md)
- [View Integration Run History](../Integrations/View_Integration_Run_History.md)

- [Download Log File](../Integrations/Download_Log_File.md)
