## Edit Macros

This topic describes how to edit macros in the Integrations, Manage, Macros page. You can also view and manage macros associated with a configuration or template.

To edit a macro

1. Click Integrations, Manage, Macros.

    The Macros page displays the available macros.

2. To edit the macro name:

    a. Click in the Macro column of the macro you want to edit.

    A text box appears.

    b. Specify a new name and press Enter.

3. To edit the macro value, click in the Value column of the macro you want to edit.

    A text box appears.

4. Specify the new value and press Enter.
5. To encrypt the macro value:

    a. Click the ![](images/UnlockIcon.png) icon in the Value column.

    b. Click SECURE MACRO.

!!! warning "Important"

    **IMPORTANT!**Secured macros cannot be unsecured, and their values cannot be edited. If you need to change the value of a secured macro, you must delete and readd it.

The ![](images/UnlockIcon.png) icon changes to the ![](images/LockIcon.png) (gray) icon which indicates that the macro value is encrypted.
