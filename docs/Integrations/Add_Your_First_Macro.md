## Add Your First Macro

If you have not created any macros, your Macros lists will be blank. If macros are already listed in the Macros list, navigate to [Add More Macros](../Integrations/Add_More_Macros.md).

To add your first private macro

1. Click Integrations, Manage, Macros.

    The Macros page displays the available macros.

2. To add macros manually:

    a. Click the Add Macro button. A blank field appears at the top of the Macro column.

    b. Specify a macro name, value and description.

3. To add macro values from a JSON or XML file:

    a. Drag and drop the macro file(s) or select Import Macros from the Add Macro dropdown, Browse Files to import the file(s).

    The macros are imported to the dialog and the filename is displayed at the top of the listed macros.

    b. To import more macros, click the Upload Macros link and repeat this step.

4. To encrypt any macro values:

    a. Click the ![](images/UnlockIcon.png) icon in the Value column.

    b. Click SECURE MACRO.

**IMPORTANT!**Secured macros cannot be unsecured, and their values cannot be edited. If you need to change the value of a secured macro, you must delete and readd it.

    The ![](images/UnlockIcon.png) icon changes to the ![](images/RuntimeWorkspace_116.png) (gray) icon which indicates that the macro value is encrypted.

5. Click CONTINUE.

The macros are added to the macros list.

To add more macros, see [Add More Macros](../Integrations/Add_More_Macros.md).
