## Include/Exclude an Endpoint

Whether an endpoint is available for selection when one configures the source to reference a service is determined by whether the endpoint is included or excluded.

To include/exclude an endpoint

1. On the Integrations Console, select Design.
2. Select Services (REST/SOAP).

3. On the Services page, click a service against which you want to include/exclude an endpoint.
An Endpoints list page opens.

4. Select single or multiple check boxes from the endpoint list to indicate those endpoints that you want to include/exclude.

    A toolbar opens with an Include endpoint ![](images/IncludeIcon.png) or Exclude endpoint ![](images/ExcludeIcon.png).

5. Click Include endpoint ![](images/IncludeIcon.png) to include the endpoint if it was excluded.

    A confirmation message displays: "Endpoint included successfully".

!!! note "Note"

    By default, all the endpoints are included for the selected service.

6. Click Exclude endpoint ![](images/ExcludeIcon.png) to exclude the endpoint.

    A confirmation message displays: "Endpoint excluded successfully".
