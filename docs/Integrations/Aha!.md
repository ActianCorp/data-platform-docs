## Aha!

Aha! is a cloud-based product management and road-mapping software designed to help teams strategize, plan, and execute product development. It provides tools for setting product strategy, capturing and organizing ideas, building visual product roadmaps, managing releases, and tracking progress. The Aha! connector provides access to data stored within Aha!.

- [Prerequisites](../Integrations/Aha!.md)
- [Connection Details](../Integrations/Aha!.md)

- [Additional Information](../Integrations/Aha!.md)

Prerequisites

You must have an Aha! service account.

Connection Details

Specify the following details to define a connection:

| Property | Description |
| --- | --- |
| API Key | The connector authenticates with the Aha! service using an API Key. Authentication requires an API Key. |
| Base URL | Your Aha account URL. For example:`https://company.aha.io` |

Additional Information

To set up credentials, see the Aha! documentation in [https://www.aha.io/api/](https://www.aha.io/api/oauth2#authorization-flow)[oauth2#authorization-flow](https://www.aha.io/api/oauth2#authorization-flow).
