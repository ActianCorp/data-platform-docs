## Edit a Service

To edit a service

1. On the Integrations Console, select Design.
2. Select Services (REST/SOAP).

3. Select the service check box from the list that you want to edit.
4. Click Edit ![](images/EditIcon.png) to modify the service. Or click Information ![](images/Information%20Icon.png) to modify the service.

5. Click Save.
A confirmation message displays: “Service updated successfully”.
You are redirected to the Services list page.
