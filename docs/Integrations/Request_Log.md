## Request Log

You can request an updated agent log file. Requesting the log file updates the Agent.log file, stored in the IntegrationAgent\logs folder.

To request a log

1. Click Integrations, Manage, Agents & Devices.

    The Agents and Devices page is displayed.

2. Click the ![](images/RuntimeWorkspace_123.png)button next to the agent of interest.
3. Select Request Log.

    The Agent.log file is updated.
