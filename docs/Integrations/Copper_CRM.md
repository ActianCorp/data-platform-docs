## Copper CRM

The Copper CRM connector helps businesses to manage their contacts and sales pipelines effectively

- [Prerequisites](../Integrations/Copper_CRM.md)
- [Connection Details](../Integrations/Copper_CRM.md)

- [Additional Information](../Integrations/Copper_CRM.md)

Prerequisites

You must have a Copper CRM account.

Connection Details

Specify the following details to define a connection:

| Property | Description |
| --- | --- |
| API Key | The API key generated from Copper CRM. See[https://developer.copper.com/introduction/authentication.html](https://developer.copper.com/introduction/authentication.html) |
| Base URL | Your API base URL. For example:`https://api.copper.com/developer_api/v1` |
| User email | Used to generate API keys. |

Additional Information

Please refer to the Copper CRM documentation for more info on the API requests and responses. API docs can be found at [https://developer.copper.com/index.html](https://developer.copper.com/index.html ).
