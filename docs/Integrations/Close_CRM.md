## Close CRM

The Close CRM connector enables you to manage the leads, contacts, and opportunities for an organization.

- [Prerequisites](../Integrations/Close_CRM.md)
- [Connection Details](../Integrations/Close_CRM.md)

- [Additional Information](../Integrations/Close_CRM.md)

Prerequisites

You must have a Close.io account.

You must configure the Close app and retrieve the API key from the app.

Connection Details

Specify the following details to define a connection:

| Property | Description |
| --- | --- |
| API Key | The API key received during your Close app creation. API keys are per organization and can be generated and deleted in the Close Settings page. |
| Base URL | Your API base URL. For example:`https://api.close.com/api/v1` |

Additional Information

Please refer to the Close documentation for more info on the API requests and responses. API docs can be found at [https://developer.close.com/](https://developer.close.com/).
