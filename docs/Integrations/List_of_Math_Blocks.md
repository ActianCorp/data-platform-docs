## List of Math Blocks

The following table lists the available [Math Blocks](../Integrations/Math_Blocks.md).

| Block | Function | Description |
| --- | --- | --- |
| [Number Block](../Integrations/Math_Blocks.md) | - | Lets you specify integers and fractional values that can be used as input in other blocks. |
| [Arithmetic Operation Block](../Integrations/Math_Blocks.md) | - | Lets you perform simple Arithmetic Operations on two numbers or numeric expressions. You can select from add, subtract, multiply, divide, and exponent operators. |
| [Absolute Value Block](../Integrations/Math_Blocks.md) | Abs(parameter) | Returns the absolute value of a number. |
| [Hexadecimal Block](../Integrations/Math_Blocks.md) | Hex(parameter) | Converts a number into a hexadecimal string. |
| [Integer Block](../Integrations/Math_Blocks.md) | Int(parameter) | Returns the integer part of a number or a numeric expression. |
| [Round Block](../Integrations/Math_Blocks.md) | Round(value, digits) | Rounds a number to a specified number of decimal places. |
