## View Connection

To view connections

1. Click Integrations, Connections.

    The Connections page displays the available connections.

2. Select the check box that is displayed for a connection, then select one of the following actions from the toolbar:

| Actions | Description |
| --- | --- |
| ![](images/DesignWorkspace_105.png) | Edit the selected connection. See [Edit Connection](../Integrations/Edit_Connection.md). |
| ![](images/DesignWorkspace_106.png) | Delete the selected connection. See [Delete Connection](../Integrations/Delete_Connection.md). |
| ![](images/DesignWorkspace_107.png) | Click this icon to search for specific text within the connection listing. Contents will be filtered based on the search string.Click ![](images/DesignWorkspace_108.png) to clear the search box. |
| ![](images/DesignWorkspace_109.png) | Click ![](images/DesignWorkspace_110.png) and then select one or more of the connection types to list connections by the selected connection types. |
