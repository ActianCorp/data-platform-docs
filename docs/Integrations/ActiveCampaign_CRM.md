## ActiveCampaign CRM

The ActiveCampaign CRM connector retrieves data from the ActiveCampaign CRM to the Actian Data Platform. The ActiveCampaign API is structured around REST, HTTP, and JSON. API endpoint URLs are organized around resources, such as contacts or deals.

- [Prerequisites](../Integrations/ActiveCampaign_CRM.md)
- [Connection Details](../Integrations/ActiveCampaign_CRM.md)

- [Additional Information](../Integrations/ActiveCampaign_CRM.md)

Prerequisites

You must have an ActiveCampaign account.

ActiveCampaign uses API Key type authentication where the user needs to authenticate the APIs using the API key provided during your account creation. Your API key can be found in your account on the Settings page under the Developer tab. For more information, please visit [https://developers.activecampaign.com/reference/authentication](https://developers.activecampaign.com/reference/authentication).

Connection Details

Specify the following details to define a connection:

| Property | Description |
| --- | --- |
| Account URL | Your account API URL. For example:`https://<your-account>.api-us1.com` |
| API version | Latest API version. |
| API Key | The API key received during your ActiveCampaign app creation. |

Additional Information

Please refer to the ActiveCampaign API documentation for more info on the API requests and responses. API docs can be found at https://developers.activecampaign.com/reference/overview.
