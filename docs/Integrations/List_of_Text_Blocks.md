## List of Text Blocks

The following table lists the available [Text Blocks](../Integrations/Text_Blocks.md).

| Block | Function | Description |
| --- | --- | --- |
| [String Block](../Integrations/Text_Blocks.md) | “” | Wraps the argument in double quotes. Mainly used to specify string values that can be used as input in other blocks. |
| [Parenthesis Block](../Integrations/Text_Blocks.md) | () | Wraps the argument in parenthesis. Mainly useful for math operations. |
| [Character Block](../Integrations/Text_Blocks.md) | Char(parameter) | Returns a string representing the ANSI character corresponding to the ASCII code (0-255) that is supplied as an integer parameter. |
| [Clean Block](../Integrations/Text_Blocks.md) | Clean(parameter) | Removes all non-printable characters from a string. |
| [Concatenate Block](../Integrations/Text_Blocks.md) | operand1 & operand2 | Creates a single string by joining two or more individual strings. |
| [Length Block](../Integrations/Text_Blocks.md) | Len(parameter) | Returns the number of characters (including spaces) in a string. |
| [Change Case Block](../Integrations/Text_Blocks.md) | Upper(parameter)Lower(parameter)Proper(parameter) | Converts the input string to UPPER, lower, or Title case, based on the option that you select from the drop-down:•UPPER – Converts to UPPER case.•lower – Converts to lower case.•Title – Converts to Title case. |
| [Trim Block](../Integrations/Text_Blocks.md) | Trim(parameter)TrimLeft(parameter)TrimRight(parameter) | Removes spaces from the beginning, end or both sides of a string, based on the option that you select from the drop-down:•Both – Removes spaces from both sides.•Left – Removes spaces from the beginning.•Right – Removes spaces from the end. |
| [Reverse Block](../Integrations/Text_Blocks.md) | Reverse(parameter) | Returns the reverse of a string. |
| [Character Count Block](../Integrations/Text_Blocks.md) | CharCount(character, string) | Counts the occurrences of a particular character in a string. |
| [Extract Characters Block](../Integrations/Text_Blocks.md) | Extract(string, charType) | Extracts characters of a specified type from a string. |
| [Replace All Block](../Integrations/Text_Blocks.md) | Replace(string, replacement, match) | Replaces every occurrence of a specific “String” with the “Replacement” string in the specified search string. |
| [Left Block](../Integrations/Text_Blocks.md) | Left(string,length) | Extracts the specified number of characters from the beginning of a given string. |
| [Right Block](../Integrations/Text_Blocks.md) | Right(string,length) | Extracts the specified number of characters from the end of a given string. |
| [Mid Block](../Integrations/Text_Blocks.md) | Mid(string,start,length) | Extracts the specified number of characters from a given string, starting from a specific position. |
