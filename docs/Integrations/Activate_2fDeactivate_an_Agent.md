## Activate/Deactivate an Agent

You can activate and deactivate an agent. Deactivating an agent pauses remote jobs associated with the agent.

To activate or deactivate an agent

1. Click Integrations, Manage, Agents & Devices.

    The Agents and Devices page is displayed.

2. Click the ![](images/RuntimeWorkspace_126.png)button next to the agent and select:

    - Activate to set the agent to Active

    - Deactivate to set the agent to Inactive

    A popup message confirms the action.
