## View Log

You can view the Agent.log file, stored in the IntegrationAgent\logs folder, in the Agent Log page.

In the Agent Log page you can search and filter log content, select Raw View to copy log file content to the clipboard for pasting, select Compact view to collapse/expand content manually, and download the log file.

To view a log

1. Click Integrations, Manage, Agents & Devices.

    The Agents and Devices page is displayed.

2. Click the ![](images/RuntimeWorkspace_124.png)button next to the agent of interest.
3. Select View Log.
