## Insightly CRM

The Insightly CRM connector allows you to get the data of various objects within an Insightly CRM account.

- [Prerequisites](../Integrations/Insightly_CRM.md)
- [Connection Details](../Integrations/Insightly_CRM.md)

- [Additional Information](../Integrations/Insightly_CRM.md)

Prerequisites

You must have an Insightly CRM account and the API key from the Insightly CRM account to authenticate the APIs. Insightly provides the API key when the account is created from the account settings page.

Connection Details

Specify the following details to define a connection:

| Property | Description |
| --- | --- |
| API Domain URL | API accessible URL. For example:`https://api.{pod}.insightly.com` |
| API version | Latest API version, for example: v3.1.**Note:**Check the Insightly API documentation for the latest version. |
| API Key | The API key received from your Insightly account settings page. |

Additional Information

Please refer to the Insightly API documentation for more information. API docs can be found at [https://api.insightly.com/v3.1/Help#!/Overview/Introduction](https://api.insightly.com/v3.1/Help#!/Overview/Introduction).
