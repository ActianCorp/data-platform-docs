## Set a Configuration as a Favorite

The Favorites option allows you to list a configuration under the Favorites tab in the Configurations page. See [View Configurations](../Integrations/View_Configurations.md).

To set a configuration as your favorite

1. Click Integrations, Manage, Configurations.

    The Configurations page lists the available configurations.

2. To add a configuration to the Favorites list, click the down arrow on the Run button and select Favorite.

    The configuration is displayed under the Favorites tab on the Configuration page.

3. To remove a configuration from the Favorites list, click the down arrow on the Run button and select Unfavorite.

    The configuration is removed from the Favorites tab on the Configuration page.
