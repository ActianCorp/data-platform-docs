## Managing Agents and Devices

An agent serves as our engine, packaged with both design and execution services. It allows users to connect to on-premises sources when designing integrations, as well as enabling the execution of jobs on that agent.

The agent must first be installed and then the users need to register it with Actian Data Platform. This registration process allows users to view and utilize the agent within both the Design and Manage spaces of Actian Data Platform, ensuring they can effectively leverage its capabilities.

Here are some situations where you might need to use an agent:

- Database connections: If you need to connect to a database that is located on your internal network.
- Internal web services: If you're working with web services that are hosted internally and aren't available to the public Internet.

- Internal files: If you're using files stored on your internal network as the source or destination for data.

!!! note "Note"

    Non-administrators can use one agent at a time.

To use an agent you must [Download an Agent](../Integrations/Download_an_Agent.md), [Install an Agent](../Integrations/Install_an_Agent.md), and [Register an Agent](../Integrations/Register_an_Agent.md).
