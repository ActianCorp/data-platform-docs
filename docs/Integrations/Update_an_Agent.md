## Update an Agent

You can update agent settings, the agent license, the agent worker and the agent engine. The agent must be in an Active state to perform these options.

To update an agent

1. Click Integrations, Manage, Agents & Devices.

    The Agents and Devices page is displayed.

2. Click the ![](images/RuntimeWorkspace_125.png)button next to the agent you want to update.
3. Select one of the following update options:

    - Update Settings – Resets the connection configuration information in the current cloud settings, and updates the values for Status and Last Check-in time.

    - Update License – Updates to the newest agent license file you have installed locally.

**Note:**You cannot manually retrieve an Agent license file outside of Actian Data Platform.

    - Update Worker – Updates to the latest version of the agent.

    - Update Engine – Updates to the latest version of Actian Data Platform.

A popup message confirms the action.

The agent is updated.
