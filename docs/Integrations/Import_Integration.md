## Import Integration

This topic provides information on how to import an integration package from your computer into the Design environment. After importing you can edit and execute the integration.

You can choose to import an existing integration from your local system, or from an Integrations File repository.

To import an Integration

1. Click Integrations, Manage, Configurations.

    The Configurations page lists the available configurations. See [View Configurations](../Integrations/View_Configurations.md).

2. Click Import Integration

    The Import Configuration page is displayed.

3. Name your integration and click one of the following buttons:

    - Local System – To choose an existing integration from your local system.

    - Integration Files – To choose an integration from an Integrations File repository.

!!! note "Note"

    Accepted file formats are: .djar,.rtc,.process,.ip.xml,.tf.xml.

4. Click Import.

    The selected configuration is imported and appears on the Integration Designs page. See [View Integration Details](../Integrations/View_Integration_Details.md).
