## Download an Agent

!!! warning "Important"

    **IMPORTANT!**When using an Agent to run an integration using the Connect via Agent option, ensure that you download the integration-agent-3.3.0-47 version or later, as previous versions are not supported.

You can download the Agent installer from either the Agents and Devices page in Actian Data Platform or Actian ESD.

To download the installer from the Agents and Devices page:

1. Click Integrations, Manage, Agents & Devices.

    The Agents and Devices page is displayed.

2. Click Download Agent and choose your platform: Windows or Linux.

    The integration-agent executable file is downloaded on your computer.

To download the installer from Actian ESD:

1. Go to [https://esd.actian.com/](https://esd.actian.com/), select Actian DataCloud Agent.
2. Click DataCloud Agent for your platform and click Download.

    The integration-agent executable file is downloaded on your computer.

After downloading the agent, you must install it. See [Install an Agent](../Integrations/Install_an_Agent.md).
