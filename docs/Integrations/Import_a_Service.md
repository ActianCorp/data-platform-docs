## Import a Service

To import a service

1. On the Integrations Console, select Design.
2. Select Services (REST/SOAP).

3. Click Import Service to import a service.
The Import Service dialog is displayed.

4. Select an import type from the provided options:

    a. OpenAPI URL

    b. OpenAPI File

    c. WSDL

    d. Other Definition File

5. (Optional) Check the Overwrite Existing Service (s)? if you want to replace a service with new definition.
6. Click Import Service.
A confirmation message displays: "Service imported successfully".
You are redirected to the Services list page.
