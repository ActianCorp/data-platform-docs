## Delete Integration

You can delete any integration that you have created by following the steps below. Once an integration has been deleted, it cannot be restored.

To delete an integration

1. Click the Integrations link at the top of the page.

    The Integration Designs page displays the available integrations. See [View Integration Details](../Integrations/View_Integration_Details.md).

2. Search and select an integration, then click ![](images/DesignWorkspace_38.png).

    The Confirm Delete dialog is displayed.

3. Type DELETE to confirm (this is case sensitive).
4. Click DELETE.

    The selected integration is deleted and no longer appears on the Integration Designs page.
