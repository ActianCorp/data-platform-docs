## Freshsales CRM

The Freshsales CRM connector is a Rest API connector which retrieves the data of each of the objects and creates specific tables in the Actian warehouse.

- [Prerequisites](../Integrations/Freshsales_CRM.md)
- [Connection Details](../Integrations/Freshsales_CRM.md)

- [Additional Information](../Integrations/Freshsales_CRM.md)

Prerequisites

You must have a Freshsales CRM account and an API Key provided by Freshsales.

Please refer to the Freshsales API Key documentation [https://developer.freshsales.io/api/#getting-started](https://developer.freshsales.io/api/#getting-started).

Connection Details

Specify the following details to define a connection:

| Property | Description |
| --- | --- |
| Domain Name | The domain name of your Freshsales CRM account. |
| API Key | The API key received during your Freshsales CRM app creation. |

Additional Information

For more information, please refer to the Freshsales CRM API documentation [https://developer.freshsales.io/api/#introduction](https://developer.freshsales.io/api/#introduction).
