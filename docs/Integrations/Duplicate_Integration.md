## Duplicate Integration

You can duplicate an integration, edit it, and reuse it.

To duplicate an integration

1. Click the Integrations link at the top of the page.

    The Integration Designs page displays the available integrations. See [View Integration Details](../Integrations/View_Integration_Details.md).

2. Search and select an integration, then click ![](images/DesignWorkspace_37.png).

    A copy of the selected integration is created with “- Copy” appended to the name. It appears on the Integration Designs page.
