## Ping an Agent

You can test the response time of an agent by pinging the agent. Pinging sends a message to the agent, which responds with a check-in message, and updates values for Status and Last Check-in time in the Agents list.

To ping an agent

1. Click Integrations, Manage, Agents & Devices.

    The Agents and Devices page is displayed.

2. Click the ![](images/RuntimeWorkspace_122.png)button next to the agent you want to contact.
