## Run an Integration Manually

!!! warning "Important"

    **IMPORTANT!**When using an Agent to run an integration with Actian Warehouse as the target, make sure the IP address of the host machine where the Agent is installed is added to the Warehouse's allowed IP list. Without this, the integration will not run. See [Update Allow List IP Addresses](../User/UpdateAllowListIPs.md).

There are three ways you can run an integration manually (without a schedule):

- From the integration editor. See [Creating Integrations](../Integrations/Creating_Integrations.md).
- From the Integration Designs page. See [Search Integrations](../Integrations/Search_Integrations.md).

- From the integration details page. See [View Integration Details](../Integrations/View_Integration_Details.md).

When an integration run is completed, runtime metrics will be available for review. See [View Integration Run History](../Integrations/View_Integration_Run_History.md).

To run an integration manually

1. Click the Integrations link at the top of the page.

    The Integration Designs page displays the available integrations.

2. Do one of the following:

    - Select the desired integration by clicking the checkbox in the tile, then click ![](images/DesignWorkspace_40.png) in the menu that appears on the top right.

    - Click the integration name and go to the integration details page, then click the Run Integration button.
