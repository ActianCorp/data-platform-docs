## Other Attribute Data Table in Netutil

The Other attribute data table in netutil specifies additional connection, encryption and authentication attributes for a vnode. For a description of each attribute and its associated values, see [Configure Vnode Attributes](../Connectivity/Establish_and_Test_a_Remote_Connection_Using_Net.md).

The Other attribute data columns are as follows:

**Type**

:   Is the type of connection, either Global or Private.

**Attr_Name**

:   Is the name of the attribute.

**Attr_Value**

:   Is the value of the attribute.
