## Supported Applications

The ODBC Driver is compatible with many database applications that use ODBC. Little or no knowledge of ODBC is required to use these applications. Some of the applications and application languages that can be used with the ODBC Driver are:

- Microsoft Access
- Microsoft Excel

- Open Office Base
- Microsoft ADO using OLE DB and ODBC

- Microsoft .NET Data Provider for ODBC (ODBC.NET)
- Microsoft .NET Data Provider for ADO using OLE DB and ODBC

- Microsoft ASP Web Pages
- Ingres Python DBI Driver

- JDBC/ODBC Bridge
- PHP ODBC Interface

- Business Objects Crystal Reports
- Microsoft Query
