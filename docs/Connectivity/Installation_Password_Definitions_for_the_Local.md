## Installation Password Definitions for the Local Instance

Users can access a remote Actian X or Vector instance using a login account set up on the remote instance’s host machine, or through an Installation Password, which allows users direct access to the instance. The Installation Password is configured for the local instance containing the databases that remote users want to access.

Detailed steps for this procedure can be found in the Procedures section of online help for Network Utility. See the online topic Adding an Installation Password.
