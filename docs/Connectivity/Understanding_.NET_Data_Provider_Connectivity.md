# Understanding .NET Data Provider Connectivity

## .NET Data Provider

The Ingres .NET Data Provider (subsequently referred to as simply the .NET Data Provider) is a Microsoft .NET component that provides native .NET connectivity to Actian Data Platform warehouses to deliver data to the Microsoft .NET Framework. It uses the Data Access Server to access Actian Data Platform data sources.

The .NET Data Provider also supports .NET access to Enterprise Access and EDBC data sources.
