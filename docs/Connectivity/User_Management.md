## User Management

When your Actian warehouse is created, the named customer contact is added as a user with database administration privileges. This user can create other users and provide them with privileges as needed.

The Actian Cloud Operations team is the system administrator as well as the security administrator for all Actian Data Platform accounts.

For more information about creating and managing additional database users, see [Manage Users](../User/Manage_Users_2.md) in the User Guide.

For more information about user management for individual cloud platforms, see [Actian Data Platform Identity and Access Management](../Security/Actian_Data_Platform_Identity_and_Access_Managem.md) in the Security Guide.

See [Data Access and Authentication](../Security/Data_Access_and_Authentication.md) in the Security Guide.
