## Server-related Tasks

In Network Utility, Servers represent server classes associated with a particular vnode. You can view a list of the servers that exist for a given vnode using the Servers branch in the Virtual Nodes toolbar/window.

From this branch, you can:

- Access a list of users on a particular server
- Connect to a local server

- Establish a connection at the user level (under a different user name)
- Disconnect at the vnode level

- Disconnect at the user level

The detailed steps for these procedures can be found in the Procedures section of online help for Network Utility. See the following topics:

- Connecting to a Server
- Impersonating Another User

- Disconnecting from a Server
- Disconnecting a User from a Server
