## Virtual Nodes Toolbar

The Virtual Nodes toolbar lets you create, alter, drop, and disconnect vnodes. The toolbar also provides features that enable you to connect to database servers and open various types of database administration utility windows.

For example, connect to the Database Object Manager and open a DOM Scratchpad. The toolbar also allows you to use an SQL Scratchpad, monitor your system performance, and display a list of Dbevents.
