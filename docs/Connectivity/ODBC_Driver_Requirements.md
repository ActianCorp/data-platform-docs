## ODBC Driver Requirements

The following sections list the ODBC driver software, platform, and protocol requirements. For more information relating to the ODBC driver, see [http://www.actian.com](http://www.actian.com). The ODBC CLI and Driver Manager are packaged with every product release, service pack, and patch.
