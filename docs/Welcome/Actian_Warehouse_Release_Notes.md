Dynamic scaling enables warehouses to scale up or down in size without a restart. This enables you to adjust resources available to a warehouse without interrupting workloads. This feature is only available in a 620.x or above warehouse. Any existing 610.x-based warehouses need to upgrade to enable this new feature.

Note: Upgrading your warehouse to enable dynamic scaling requires a support ticket. New warehouses use 620.x warehouses by default.

For more information, see [Scale a Warehouse](../User/ScaleWarehouse.md)

The architecture for Avalanche is updating for AWS. AWS AV-2 is a distinction that the architecture has been refreshed for AWS and it supports the same features as Google Cloud. AWS AV-1 is still supported, meaning customers that have warehouses built on AWS AV-1 are keeping the legacy functionality without being forced to go to the AV-2 functionality. When there are differences in the architecture, the documentation will note AWS AV-1 versus AWS AV-2.
