# What’s New in Actian Data Quality

Actian Data Quality on the Actian Data Platform introduces Data Profiling, which addresses data quality rules, statistical summaries, and charts to help detect and correct flaws in your data, as well as provide insight to limit or prevent data quality issues in the future. Actian Data Profiling analyzes dataset attributes and provides insights into their quality and structure without requiring manual examination of each element. Data Profiling establishes a connection to a data source, then establishes data quality rules to run against the data, and logs and shows the results of your data quality.

Data Profiling features include:

- Recognizing common data patterns and flagging deviations
- Rules to inspect source data and make data quality recommendations

- Referencing the source data to configuring data profile rules
- Creating statistical summaries and drill down charts to identify and isolate data quality issues.

- Isolating invalid data
- Capturing historical trends for each data profile
