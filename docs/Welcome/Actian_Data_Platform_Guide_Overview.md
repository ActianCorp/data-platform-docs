# Actian Data Platform Guide Overview

**Actian Data Platform Tutorials**

:   Helps you quickly understand basic tasks and leads you to accomplish them.

**Warehouse User Guide**

:   Describes how to create, manage, and monitor an Actian warehouse, and use the Query Editor to start querying your data.

**Data Loading Guide**

:   Describes how to load data into Actian using the Desktop Data Loader and Batch Data Loading facilities. It also details how to load data from external tables in Cloud storage.

**Connectivity Guide**

:   Describes how to establish and maintain communications between Actian instances and how to use ODBC, JDBC, and .NET data provider connectivity components.

**Security Guide**

:   Describes the Actian Data Platform security features and includes instructions for defining various types of users and authorizing user access.

**SQL Language Guide**

:   Describes SQL language elements and their proper use; details about managing transactions and handling errors; and database procedures, sessions, and events.

**Integrations Guide**

:   Describes how to design, manage, and monitor an Actian Integration.

**Database User Guide EAP**

:   Early Access to create, load, and manage Ingres databases, and use the Query Editor to start querying your data.
